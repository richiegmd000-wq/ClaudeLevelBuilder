# ClaudeLevelBuilder

A Geode mod for Geometry Dash. Open the level editor, tap the Claude button, describe the level you want, and Claude builds and decorates it for you.

## Setup
1. Install the .geode file from the Actions build output.
2. Open the mod settings and enter your Anthropic API key.
3. Open the editor, tap Claude, and describe your level.

## Build
The mod is built automatically with GitHub Actions. Run "Build Geode Mod" in the Actions tab and download the Build Output artifact.
